## [1.0.0] — 2026-10-08

Первый стабильный релиз.

### Установка
- Одна команда с нуля: `bx setup --defaults --edition standard --install --clean` (около 1,5 минут):
  Docker, окружение, HTTPS, мастер установки Битрикса без браузера, очистка демо-данных.
- Мастер Битрикса проходится по HTTP (`bx install`): без регистрации продукта по умолчанию или с ней
  (`--register --reg-name --reg-surname --reg-email`); `--skip-updates` пропускает обновления в мастере.
- Редакции «Старт», «Стандарт», «Малый бизнес», «Бизнес»; MySQL 8.4 и 8.0, MariaDB 11.4 и 10.11; PHP 8.3 и 8.2.
- Неинтерактивная настройка флагами (`--defaults`, порты, база, администратор и др.), пароли БД по умолчанию случайные.

### Команды
- `bx update` — обновление платформы Битрикса (как «Обновление платформы» в админке), со снимком перед обновлением.
- `bx clean` — удаление демо-данных, остатков и модулей штатными деинсталляторами; защищены `main`, `security`, `fileman`, `ui`.
- `bx backup` / `bx restore` — снимки (база, файлы сайта, `local`) и откат одной командой.
- `bx https` — HTTPS с сертификатом mkcert или самоподписанным, редирект, свои домены.
- `bx doctor` — диагностика Docker, портов, сайта, HTTPS, кеша модулей, агентов, паролей и диска.
- `bx passwords rotate` — смена паролей БД в базе, `.env` и настройках Битрикса.
- `bx cron`, `bx debug`, `bx cache-clear`, `bx sql`, `bx php`, `bx open`, `bx version` и управление контейнерами.

### Окружение
- php-fpm, nginx, MySQL/MariaDB, cron для агентов Битрикса, Mailpit (ловушка почты) и Adminer.
- Файлы Битрикса лежат в томе Docker (на macOS файловая система не различает регистр, и обновления теряют файлы).
- Версии образов закреплены; порты базы, Mailpit и Adminer открыты только на 127.0.0.1.

### Проверки
- GitHub Actions: `shellcheck`, синтаксис PHP, `docker compose config` и сквозная установка с нуля на Linux.
- Вручную проверены все редакции и базы полным циклом (установка, очистка, диагностика, вход, откат) на macOS.

### Известные ограничения
- Windows и WSL не проверялись.
- Режима «у меня есть лицензионный ключ» нет (только регистрация по почте).
- `bx update` в CI не проверяется (нужна регистрация), проверен вручную.
