# Безопасность

## Как сообщить об уязвимости

Пожалуйста, **не создавайте публичный issue**. Используйте закрытое сообщение GitHub:
[Report a vulnerability](../../security/advisories/new) (вкладка Security → Report a vulnerability).
Опишите, что найдено, как воспроизвести и чем это грозит. Отвечу в течение нескольких дней.

## Что считается уязвимостью

Например: утечка паролей или `.env`, выполнение чужого кода через скрипты `bx`, открытые наружу порты базы и служебных
сервисов, небезопасная работа с файлами снимков и сертификатами.

## Поддерживаемые версии

Исправления выходят для последней версии (см. [релизы](../../releases)).

## Что уже сделано

Порты базы, Mailpit и Adminer открыты только на `127.0.0.1`; пароли БД по умолчанию случайные, `.env` с правами 600;
версии образов закреплены; PHP-файлы в `upload/` не выполняются; служебные папки Битрикса закрыты в nginx.
Проект рассчитан на **локальную разработку**; для боевых серверов он не предназначен.
